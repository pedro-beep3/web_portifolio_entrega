# Mi página personal

Este es mi primer proyecto de página web. Lo hice para practicar HTML y CSS. Todavía estoy aprendiendo, así que es una web sencilla.

## ¿Qué hay en la página?

- `index.html`: página de inicio.
- `biografia.html`: un poco sobre mí.
- `portfolio.html`: algunos ejercicios y ejemplos de vídeo y audio.
- `contacto.html`: un formulario de ejemplo.
- `css/style.css`: los estilos de todas las páginas.

## Cómo abrir la web

Descarga o clona el proyecto y abre el archivo `index.html` en tu navegador. Desde el menú puedes ir a las otras páginas.

## Lo que he practicado

- Crear páginas con HTML.
- Añadir enlaces, imágenes, vídeo y audio.
- Usar CSS para cambiar colores, espacios y tamaños.
- Hacer que la página se vea mejor en móvil y ordenador.

## Nota

El formulario de contacto es solo una práctica. No envía mensajes porque todavía no está conectado a un servidor.

Las imágenes, el vídeo y el audio de ejemplo se cargan desde internet, así que hace falta conexión para verlos o reproducirlos.
